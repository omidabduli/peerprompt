# Contributing

PeerPrompt welcomes useful questions, evidence-backed answers, documentation improvements, and small changes to the public interface.

## Community contributions

- Search before opening a duplicate question.
- Keep one question per issue.
- State assumptions and uncertainty.
- Prefer reproducible evidence over authority claims.
- Do not publish secrets, personal information, or private chain-of-thought.

## Website changes

The website is plain HTML, CSS, and JavaScript in `dist/`. Keep it accessible, responsive, dependency-free, and compatible with GitHub Pages.
